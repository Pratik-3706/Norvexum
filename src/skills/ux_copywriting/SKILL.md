# UX Copywriting Principles

Use these rules to write clear, actionable text that guides users through the application interface.

## User-Focused Terminology
Use terms that correspond directly to user actions and real-world concepts, rather than database schemas or technical implementations. For instance, write "Account Settings" instead of "Database User Meta", or "Notification Rules" instead of "Webhook Subscription Array".

## Actionable Verb Triggers
Formulate button labels and commands using active verbs that state exactly what happens when clicked. Use specific labels like "Save Draft" or "Publish Article" instead of general labels like "Submit" or "Ok". Ensure language remains consistent throughout the workflow. For example, a button labeled "Activate System" should trigger a notification confirming "System Activated".

## Detailed Guidance on Failures
When an error or empty state occurs, write clear instructions explaining what went wrong and how the user can resolve it. Refrain from vague error messages like "An unexpected error occurred" or unnecessary apologies. Treat empty tables as opportunities to direct the user toward a constructive action (e.g. "No skills added yet. Click 'Create Skill' to get started").

## Conversational Tone & Sentence Case
Keep the text clean, conversational, and direct. Use sentence-case capitalization for headers and labels. Avoid filler words and promotional marketing slogans in tooltips or descriptions, letting each text label perform a single, clear job.
